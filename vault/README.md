# «Хранилище» — игра с загадками для Недели финансовой грамотности

Сайт, на котором по расписанию открываются загадки («замки»). Кто решает раньше, получает больше баллов. Вход и оповещения идут через ботов Telegram и ВКонтакте.

Внешних зависимостей нет: нужен только **Node.js 22.13 или новее**. База данных — один файл SQLite в папке `data/`.

## Что есть

| Адрес | Что это |
|---|---|
| `/` | Сайт для игроков: замки, таймеры, ответы, подсказки, таблица лидеров |
| `/board` | Таблица лидеров на большой экран (`/board?n=20` — сколько строк показывать) |
| `/admin` | Админка: замки, участники, попытки, рассылка, настройки |
| `/stage/hack` | Экран для сцены: «взлом» презентации. Пробел — запуск, R — сброс, F — полный экран |
| `/stage/trap` | Экран для сцены: QR «бесплатный кофе». Пробел — счётчик попавшихся, B — назад |
| `/coffee` | Страница, на которую ведёт QR-ловушка. Ничего не собирает, только считает переходы |

## Запуск на своём компьютере

```bash
cp .env.example .env      # вписать ADMIN_PASSWORD и поставить DEV_LOGIN=1
npm start                 # сайт откроется на http://localhost:3000
npm test                  # автопроверка основных сценариев
```

С `DEV_LOGIN=1` в окне входа появляется кнопка «Тестовый вход» — можно играть без ботов.

## Запуск на сервере (VPS с Ubuntu)

1. Поставить Node.js 22: `curl -fsSL https://deb.nodesource.com/setup_22.x | sudo bash - && sudo apt install -y nodejs`
2. Скопировать папку `vault` на сервер, например в `/opt/vault`.
3. `cp .env.example .env` и заполнить (см. ниже). `DEV_LOGIN` оставить `0`.
4. Сделать автозапуск — файл `/etc/systemd/system/vault.service`:

   ```ini
   [Unit]
   Description=Vault
   After=network.target

   [Service]
   WorkingDirectory=/opt/vault
   ExecStart=/usr/bin/node --no-warnings server.js
   Restart=always

   [Install]
   WantedBy=multi-user.target
   ```

   Затем `sudo systemctl enable --now vault`. Журнал: `journalctl -u vault -f`.
5. Нужен домен и HTTPS. Проще всего через Caddy (`sudo apt install caddy`), файл `/etc/caddy/Caddyfile`:

   ```
   твой-домен.ru {
       reverse_proxy localhost:3000
   }
   ```

   `sudo systemctl reload caddy` — сертификат выпустится сам. В `.env` указать `BASE_URL=https://твой-домен.ru`.

Резервная копия — это папка `data/` (база и загруженные картинки). Перед стартом недели и каждый вечер её стоит копировать.

## Настройка ботов

### Telegram
1. Написать [@BotFather](https://t.me/BotFather): `/newbot`, придумать имя. Он выдаст токен.
2. В `.env`: `TG_BOT_TOKEN=токен`, `TG_BOT_USERNAME=имя_бота`.

Если сервер стоит в России и `api.telegram.org` с него недоступен, бот не заработает. Проверка: `curl -I https://api.telegram.org`. Обход — переменная `TG_API_BASE` с адресом своего прокси.

### ВКонтакте
1. Создать сообщество (или взять существующее). Управление → Сообщения → **включить сообщения сообщества**.
2. Управление → Работа с API → Ключи доступа → создать ключ с правом **«сообщения сообщества»**.
3. Там же вкладка Long Poll API: **включить**, версия API 5.199, в «Типах событий» отметить **«Входящее сообщение»**.
4. В `.env`: `VK_GROUP_TOKEN=ключ`, `VK_GROUP_ID=числовой id сообщества`, `VK_GROUP_SCREEN=короткое имя из адреса vk.com/…`.

### Как игрок входит
Нажимает «Войти», выбирает мессенджер и получает код из 6 символов. В Telegram код уходит боту сам по кнопке, во ВКонтакте его нужно отправить сообщением. Бот подтверждает, сайт входит сам. Один аккаунт мессенджера — один игрок.

## Как устроены баллы

- Замок сначала стоит `max` баллов и равномерно дешевеет до `min` за заданное число минут. Все три числа задаются в админке для каждого замка.
- Первым трём решившим бонус: +30, +20, +10.
- Неверный ответ: −2 балла, но не больше −20 за замок. Между попытками пауза 20 секунд.
- Подсказки открываются по порядку, цена вычитается из награды за этот замок.
- Меньше 10 баллов за решённый замок не бывает.

Правила лежат в `lib/scoring.js`.

## Как добавить загадку

Админка → «Замки» → «Добавить замок». Текст пишется в HTML, картинки и аудио загружаются кнопкой «Загрузить и вставить». Правильных ответов может быть несколько, по одному в строке. Регистр, пробелы, знаки препинания и «ё/е» при проверке не учитываются.

Пока замок не открыт по таймеру, сервер не отдаёт игрокам ни название, ни текст, ни файлы — подсмотреть заранее через код страницы нельзя. Ответы и текст загадок хранятся только в базе на сервере, в репозиторий они не попадают.

## Перед выступлением

- Админка → «Настройки и сцена» → обнулить счётчик ловушки.
- `/stage/hack` показывает время открытия ближайшего закрытого замка, поэтому замок №1 должен быть создан и опубликован заранее.
- Свой слайд вместо стандартного «скучного»: загрузить картинку слайда через админку и открыть `/stage/hack?bg=/uploads/имя_файла.png`.
- Текст сообщения «Хранителя» меняется в начале скрипта в `public/stage-hack.html` (массив `LINES`).
- Звук помех идёт из браузера — проверить, что компьютер подключён к колонкам зала.
