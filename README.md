# Робот-инвестор (прототип)
10 ликвидных акций MOEX (TQBR), 5 лет, макро (IMOEX, USD/RUB, ключевая ставка), новости (RSS, лексикон).
Модели: линейная регрессия и дерево решений, walk-forward без утечки. Портфель: long-only, лимит 25% на бумагу,
таргет волатильности, стоп по просадке, комиссии. Запуск: `pip install -r requirements.txt && python run.py` → `report.md`, `reports/equity.png`.
Ограничение: история новостей недоступна (RSS), в прошлом новостной признак = 0.
